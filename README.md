Task 5: Deploy a Static Website Using GitHub Pages

Project Overview

This project is part of my Web Development Internship at Elevate Labs.

The objective was to create a simple static website using HTML and CSS and deploy it for free using GitHub Pages.

Technologies Used

- HTML5
- CSS3
- Git & GitHub
- GitHub Pages

Features

- Simple and clean portfolio design.
- About Me section.
- Skills section.
- Contact section.
- Navigation links.
- Interactive button using JavaScript.
- Responsive layout.

Project Structure

portfolio-website/
│
├── index.html
└── README.md

Deployment

The website was deployed using GitHub Pages.

Steps followed:

1. Created a public GitHub repository.
2. Uploaded the website files.
3. Opened repository Settings.
4. Enabled GitHub Pages using the main branch.
5. Accessed the live website through the GitHub Pages URL.


Learning Outcomes

- Learned the basics of static website hosting.
- Understood Git and GitHub workflow.
- Learned how to deploy a website using GitHub Pages.
- Understood the process of updating a deployed website.
